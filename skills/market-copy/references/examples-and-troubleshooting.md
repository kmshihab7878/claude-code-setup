# Examples And Troubleshooting

Purpose: CTA examples, before/after format, swipe-file requirements, editing rubrics, anti-patterns, and troubleshooting.

## CTA Optimization

Button text:

- Use first person when it fits: "Start My Free Trial."
- Include value: "Get My Report" rather than "Submit."
- Reduce risk: "Try Free for 14 Days" when true.
- Be specific: "Download the 2026 Marketing Guide" rather than "Download."
- Add urgency only when the urgency is real.

Placement:

- CTA above the fold is required for conversion pages.
- CTA after each major section is recommended on long pages.
- Sticky or floating CTA can help long-form pages when it does not obscure content.
- Final CTA at the bottom is required for long conversion pages.

Color:

- Ensure strong contrast with the page background.
- Choose color according to the design system before relying on color psychology.
- Do not use color as the only way to communicate hierarchy.

## Before/After Pair Format

```text
BEFORE:
  "[current copy]"

AFTER:
  "[recommended copy]"

WHY:
  [Specific reason: clarity, specificity, proof, audience fit, CTA alignment, or reduced friction.]
```

Generate at least five pairs covering:

1. Primary headline.
2. Subheadline.
3. Primary CTA.
4. One body-copy paragraph.
5. Meta description.

## Worked Example

```text
BEFORE:
  "Solutions for busy teams."

AFTER:
  "Plan, assign, and approve every client task from one shared workspace."

WHY:
  The rewrite names the actions, audience context, and concrete operating benefit.
```

## Swipe File Requirements

Create:

- 10 headline alternatives ranked by estimated effectiveness.
- 5 subheadline alternatives.
- 5 CTA button alternatives.
- 3 meta description alternatives.
- 3 social-proof framing alternatives.
- 3 pricing page headline alternatives when applicable.

Each entry should include framework label, audience, proof requirement, and compliance note if relevant.

## Editing Rubric

- Cut vague adjectives.
- Replace feature lists with outcomes.
- Use active verbs.
- Use concrete nouns.
- Keep one idea per sentence in hero and CTA copy.
- Preserve brand voice unless there is a clear conversion reason to change it.
- Add proof where claims are specific.

## Anti-Patterns

- Generic claims that could fit any competitor.
- Unsupported metrics or outcomes.
- CTA text that hides the real next step.
- Multiple primary CTAs competing above the fold.
- Jargon-heavy hero copy.
- Fake scarcity or countdowns.
- Benefits that are really features with adjectives attached.

## Troubleshooting

If copy still feels vague:

- Identify the exact reader, job-to-be-done, and pain.
- Replace abstractions with a concrete workflow or outcome.
- Add proof or reduce specificity.

If copy feels too aggressive:

- Remove false urgency.
- Replace fear-led language with problem-aware language.
- Use direct proof instead of pressure.

If the CTA underperforms:

- Check whether the action matches the reader's stage.
- Reduce friction around the CTA.
- Add proof or risk reversal near the button.

If stakeholders reject rewrites:

- Show before/after rationale.
- Tie each change to the scoring rubric.
- Offer a lower-risk voice-preserving version.
