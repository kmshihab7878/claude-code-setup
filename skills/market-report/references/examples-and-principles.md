# Marketing Report Examples and Principles

This reference contains public-safe examples and quality principles for client-ready marketing reports.

## Key Principles

- The report should be strong enough to support a client engagement conversation.
- Lead with insights and opportunities, not criticism.
- Quantify where possible, but label estimates clearly.
- Make action plans specific enough for a junior marketer to execute.
- Use professional formatting: headings, tables, checkboxes, and clear hierarchy.
- Reference specific source findings when available.
- Be transparent about analysis versus estimation.
- Tell a story: where the business is, where it could be, how to get there, and what it is worth.

## Executive Summary Example

```markdown
## Executive Summary

The current marketing system has a solid foundation in [strength], but growth is constrained by [primary bottleneck]. The highest-impact opportunity is [recommendation], which is expected to improve [metric] based on [source finding].

The report identifies three near-term priorities: [priority 1], [priority 2], and [priority 3]. Together, these changes address the largest conversion and acquisition gaps while creating a measurement baseline for future optimization.
```

## Recommendation Example

```markdown
- [ ] Rewrite the hero section around the primary buyer pain.
  - Evidence: Landing audit found the current value proposition takes multiple sections to understand.
  - Impact: HIGH
  - Effort: 3-5 hours
  - Expected Result: Higher CTA click-through and lower bounce from paid traffic.
  - Revenue Impact: Estimate requires current traffic and conversion data.
```

## Assumption Language

Use explicit labels:

- `Verified`: sourced from audit output or user-provided data.
- `Estimated`: calculated from assumptions that are shown.
- `Insufficient data`: not enough evidence to score confidently.
- `Recommended next measurement`: data needed to improve confidence.

## Final Quality Check

Before delivery:

- Does the executive summary explain what matters?
- Are category scores defensible?
- Are recommendations specific?
- Are estimates labeled?
- Is the action plan executable?
- Does the roadmap sequence dependencies realistically?
- Are limitations visible?
