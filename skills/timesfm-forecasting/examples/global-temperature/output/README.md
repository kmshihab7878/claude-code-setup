# Generated example artifacts

Files in this directory are **build outputs** produced by the sibling example
scripts. They are tracked so consumers of the skill can see what a successful
run looks like without having to re-execute it.

| File | Generated by | Consumed by |
|---|---|---|
| `forecast_output.csv` | `../run_forecast.py` | acceptance criteria in SKILL.md |
| `forecast_output.json` | `../run_forecast.py` | acceptance criteria in SKILL.md |
| `forecast_visualization.png` | `../visualize_forecast.py` | acceptance criteria in SKILL.md |
| `animation_data.json` | `../generate_animation_data.py` | `../generate_gif.py`, `../generate_html.py` |
| `forecast_animation.gif` | `../generate_gif.py` | (terminal output) |
| `interactive_forecast.html` | `../generate_html.py` | (browser output) |

To regenerate every file from scratch:

```
python ../run_forecast.py
python ../visualize_forecast.py
python ../generate_animation_data.py
python ../generate_gif.py
python ../generate_html.py
```

These are reference artifacts, not capability-defining instructions. They are
lazy — they enter context only when something explicitly reads them. The
context-budget report classifies them as `ACCEPTABLE_LARGE`. Do not compress
or summarize them; they exist precisely to show real generated output.
