# Messaging Templates

Purpose: Value proposition, persona messaging, competitive response, objection handling, and channel copy templates.

## Value Proposition

```text
[Product] helps [Target Customer] [Achieve Goal] by [Unique Approach].
```

## Persona Messaging

| Persona | Message Focus |
|---|---|
| Economic Buyer | Business outcomes, ROI, risk reduction |
| Technical Buyer | Integration, reliability, security, implementation |
| User/Champion | Ease of use, speed, daily workflow improvement |

## Competitive Response Script

```text
If the buyer says: "[competitor objection]"
Respond with: "[acknowledge + differentiated value + evidence]"
Then ask: "[qualifying question]"
```

## Objection Handling

```text
Objection: [what the buyer says]
Reality: [what is underneath]
Response: [short answer]
Proof: [source, case study, benchmark, or placeholder]
Next step: [low-friction action]
```

## Channel-Specific Copy

- Landing pages: headline, subhead, proof, CTA, FAQ.
- Email: problem, trigger, proof, CTA.
- Ads: audience, pain, outcome, proof, CTA.
- Sales deck: problem, impact, solution, differentiation, proof, next step.
